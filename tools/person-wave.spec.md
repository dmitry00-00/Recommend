# Почерк автора — правила разметчика

Приложение recomend подбирает фильмы, сериалы и книги «на шаг сложнее привычного». У каждого произведения есть разметка: уровень сложности 1–10, когнитивные операции, барьеры, строка «что делает со зрителем». Теперь нужна такая же разметка для **авторов** — режиссёров, создателей сериалов, писателей: каков их почерк, чего ждать от их вещей в целом. Это пойдёт на страницу автора и в подбор «по автору».

## Вход
TSV-строки: `элемент Wikidata 	 имя 	 имя в оригинале 	 роли у нас 	 годы жизни 	 описание из Wikidata 	 известность 	 его произведения у нас`.
- Произведения у нас — через « | »: `Название (год), вид, ур. N: строка разметки`. Это уже размеченные вещи из нашего каталога (до 14, равномерно по карьере); уровня и строки может не быть.
- Известность — число разделов Википедии о человеке.

## Выход
Файл JSON (путь в задании): массив объектов
```json
{"id":"Q882","level":[2,6],"ops":[["perspective_taking",0.6],["critical_analysis",0.5]],"barriers":["Немое кино"],"what":"…","confidence":"high","by":"memory"}
```
Проверь в конце: `python3 -c "import json;print(len(json.load(open('…'))))"`.

## Поля
- **level** — `[нижний, верхний]`, 1–10: диапазон, в котором обычно лежат его вещи (не крайние выбросы). Опирайся на уровни его произведений во входе — они размечены по общей шкале: детское и аттракцион 1; массовое 2–3; умное массовое 4; авторское с доступным входом 5–6; сложная форма 6–7; медленное авторское 7–8; 9–10 почти не бывает. Узкий диапазон (2 ступени) у ровного автора, широкий — у того, кто снимал и блокбастеры, и авторское.
- **ops** — 1–3 фирменные операции, которых требуют его вещи, с интенсивностью 0.2–0.9, по убыванию. Только из списка: `pattern_recognition` (повторы, мотивы, ключи), `causal_reasoning` (причины и следствия, интрига, детектив), `perspective_taking` (встать на место другого), `analogical_thinking` (притча, аллегория), `synthesis` (сложить много линий), `abstraction` (идеи, философия, символ), `metacognition` (о восприятии, ненадёжность взгляда, вещь о самой себе), `critical_analysis` (сатира, разбор общества).
- **barriers** — 0–3 барьера, типичных для его вещей, только из списка: «Медленный темп», «Сатирическая условность», «Хоррор-образы», «Нелинейное время», «Размытая граница реальности», «Без сюжета в привычном смысле», «Долгий хронометраж», «Разговорная форма», «Нарастающий дискомфорт», «Фрагментарная структура», «Одна комната», «Театральная манера», «Непривычная мифология», «Мало слов», «Много линий», «Ненадёжный рассказчик», «Условная актёрская манера», «Смена жанра», «Смена рассказчиков без предупреждения», «Найденная плёнка», «Архаичная речь», «Кукольная эстетика», «Чёрно-белое изображение», «Немое кино», «Музыкальные номера», и книжные: «Большой объём», «Язык теряется в переводе», «Архаичный язык», «Поток сознания», «Много персонажей», «Исторический контекст».
- **what** — одна строка по-русски, 60–160 знаков: что его вещи делают со зрителем или читателем, через двоеточие; узнаваемый почерк, а не биография и не перечень наград. Без рекламных слов. Образцы:
  - «Бродяга против машин и богачей: комедия, где смех держится на жалости, а трюк — на точной пантомиме.»
  - «Время течёт медленно, вода и огонь значат больше слов: кино-медитация о памяти, вере и вине.»
  - «Хладнокровные загадки с подменой точки зрения: следишь за временем и деталями, а финал переворачивает всё увиденное.»
- **confidence** — `high`, если хорошо знаешь автора; `medium`, если знаешь в общих чертах или выводишь по его произведениям во входе; `low` — почти ничего не ясно (в продукт не идёт).
- **by** — `memory`, если знаешь автора сам; `works`, если не знаешь и выводишь почерк из его произведений во входе (тогда confidence не выше `medium`).

## Главное правило
**Не выдумывай.** Знаешь автора — по знанию. Не знаешь, но во входе есть его произведения со строками разметки — выводи почерк из них (`by: works`). Нет ни знания, ни строк (только названия без разметки) — пропусти. Тёзки: сверяйся с годами жизни, описанием и списком произведений — почерк того человека, чьи это вещи.

Автор одной вещи: почерк — по этой вещи, диапазон узкий, `confidence` не выше `medium`, если знаешь только её.

## Отчёт
В конце коротко: сколько размечено (из них по произведениям), сколько пропущено, 5 пропущенных с причиной; отдельно — подозрения на ошибку (чужие произведения в списке, тёзки, не тот человек).
